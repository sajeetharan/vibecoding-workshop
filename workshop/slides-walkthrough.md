# Slide Walkthrough Script (Facilitator)

Use this as your speaking companion while presenting `slides-vibe-coding.md`.

## 0-10 min: Slides 1-4
Goal:
- Set expectations and outcomes.

Say:
- "This workshop is about shipping software with AI support, not outsourcing thinking."
- "By the end, everyone has a public Cloud Run URL."

Ask:
- "Who has used Cursor before?"
- "Who has deployed to cloud before?"

## 10-30 min: Slides 5-10
Goal:
- Teach prompt patterns with examples.

Say:
- "Bad prompts create rework. Good prompts create predictable diffs."

Live activity:
- Ask students to rewrite one vague prompt into a scoped one.

## 30-85 min: Slides 11-12
Goal:
- Build core app in pairs.

Checkpoint at 20 min:
- app runs locally.

Checkpoint at 40 min:
- POST and GET flow both working.

## 85-105 min: Break + troubleshooting window
Goal:
- Let blocked teams recover.

Facilitator action:
- Visit each team, remove blockers quickly.

## 105-145 min: Slide 13
Goal:
- Improve quality and clarity.

Prompt suggestion:
- "Improve error handling and accessibility with minimal code changes."

## 145-180 min: Slides 14-16
Goal:
- Deploy and validate Cloud Run service.

Checkpoint:
- every team has a URL and working `/api/health`.

## 180-210 min: Slides 17-22
Goal:
- Reflect on engineering judgment.

Say:
- "AI can suggest code. You still own reliability and user outcomes."

## 210-240 min: Slides 23-24
Goal:
- Team demos and close.

Demo format:
1. what they built,
2. one AI-assisted win,
3. one human decision,
4. live URL.

## Backup Plan if Time Is Short
- Skip advanced stretch goals.
- Keep only one quality improvement task.
- Move reflection to async submission.
